# Solo Builder Outreach Pattern

When discovering a fellow solo builder in the agent economy ecosystem (0-5 stars, 1-2 contributors, small repos), the play is a **relationship**, not a PR.

## Signal Detection

- Repo has 0-5 stars, 1-2 contributors
- Building in the same space (x402, agent payments, ERC-8004)
- No open issues to fix (or only 1-2)
- Last commit within 3 months
- Solo dev or very small team

## Outreach Pattern

1. **Star the repo** — first signal
2. **Clone and analyze** — understand what they built
3. **Open an issue introducing yourself** — not a PR, a conversation starter

### Message Template

```
Hey [name] — I'm Jordan, building GenTech Labs (gentechlabs.net). We run a production x402 gateway with [N] live endpoints across multiple chains.

Saw your [repo/skill/SDK] — solo builder myself, grinding the same space. Happy to help with issues, maintenance, whatever you need. Let's build this together.

Also — we'd love to [list our gateway / integrate / cross-pollinate]. More volume for both of us.
```

## When to Use

- Fellow solo builder in the same ecosystem (e.g. Ivaavi.eth — Singularity SDK, x402-Layer ClawHub Skill)
- No open issues to fix — the play is a conversation, not a PR
- First star, first potential contributor — high signal-to-noise ratio

## Follow-up

- Save integration plan to `10-Labs/<project>-integration-plan.md`
- Add to build queue if collaboration opportunity identified
- Offer to help with open issues (even if only 1)
- Consider contributing a PR after relationship is established
