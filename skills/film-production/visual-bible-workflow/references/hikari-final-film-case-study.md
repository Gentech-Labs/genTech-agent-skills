## Key Lessons
1. **Bangs-over-eye is the only method needed** — 100% pass rate, no artifacts, no face shift
2. **Muffin's description must be copy-pasted verbatim** into every prompt to prevent drift
3. **Behind-angle shots** are the safest for establishing scenes
4. **Scenery blend** is unreliable — don't use unless Vanito asks
5. **Virtual Portrait** changes character appearance — don't suggest
6. **Wallet management**: ~$1.60 per 5s clip, ~$2.55 per 8s clip, ~$4.46 per 14s clip
7. **SCP download issue**: BlockRun URLs timeout on batch curl with `&` in URL. Download one at a time with `--connect-timeout 30 --max-time 180` for large files
