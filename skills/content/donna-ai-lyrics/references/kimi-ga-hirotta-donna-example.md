## Rules This Demonstrates

1. **Simple tags** — `[Verse]`, `[Chorus][Scream]`, `[Bridge]`, `[Outro]` — no stacking beyond one tag line
2. **`[Scream]` is the ONLY additional tag** for aggressive sections
3. **No voice tags** (`[Male]`, `[Female]`, `[Duet]`) — Donna handles this
4. **No emotion tags** (`[Angry]`, `[Cocky]`, etc.) — the lyrics carry the tone
5. **`[Intro]`** for instrumental opening — short description on the next line
6. **Blank line between sections** — no `---` dividers
7. **No markdown formatting** inside lyrics
