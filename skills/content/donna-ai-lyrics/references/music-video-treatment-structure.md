# Music Video Treatment Structure

How to write a scene-by-scene music video treatment for Vanito's songs.

## Format

```
**Timestamp — SECTION NAME]**
*Camera direction, lighting, mood.*

Song lyric that plays here

Description of what the viewer sees — actions, cuts, flashbacks, character movements.

*Quick cuts / transitions:*
- Visual beat 1
- Visual beat 2
- Visual beat 3
```

## Standard Beat Map (for a 4-5 min song)

| Timestamp | Section | Visual Focus |
|-----------|---------|--------------|
| 0:00–0:20 | Intro | Establish setting, character in place, slow build |
| 0:20–0:52 | Verse 1 | Flashback or backstory visuals, warmer/grainier filter |
| 0:52–1:11 | Pre-Chorus | Build tension, camera circles character, first step forward |
| 1:11–1:41 | Chorus | Full energy, wide stage shots, crowd, character reaching out |
| 1:41–2:08 | Verse 2 | Second flashback, character reactions, emotional close-ups |
| 2:08–2:27 | Pre-Chorus 2 | Stronger build, character glances |
| 2:27–2:57 | Chorus 2 | Full power, crowd goes crazy, harmony moment |
| 2:57–3:25 | Bridge | Music drops to piano/vocals, intimate close-up, raw moment |
| 3:25–4:08 | Final Chorus | Everything peak, scream, crowd eruption, freeze frame |
| 4:08–4:33 | Outro | Fade back to same position as intro, but changed, slow fade to black |

## KAGE × HIKARI Visual Language

- **KAGE shots**: Dark red lighting, guitar in hand or nearby, brooding silhouette, back-view or profile
- **HIKARI shots**: Spotlight, microphone, reaching upward, warm backlighting, hair catching light
- **Together shots**: Side-by-side facing the same direction, hand-holding, one step ahead/behind dynamic
- **Flashback filter**: Slightly warmer colors, slight grain overlay, softer edges
- **Stage lighting progression**: Dim single spot (intro) → full band wash (chorus) → backlit silhouette (bridge) → full fireworks (final chorus)

## Camera Direction Keywords

- Slow zoom / dolly in / dolly out
- Steadicam through crowd
- Close-up on hands / face / mic
- Wide establishing shot
- Jump cut / cross dissolve / fade
- Split screen
- Freeze frame

## Story Arc Template

1. **Establish** — character alone, missing something
2. **Memory** — flashback to how they met/found each other
3. **Struggle** — showing the pain/tension
4. **Connection** — the moment they reach out
5. **Transformation** — everything changes, full band, crowd
6. **Resolution** — back to the same place as the start, but now complete
