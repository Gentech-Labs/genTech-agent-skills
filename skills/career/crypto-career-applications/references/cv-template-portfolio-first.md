## Key Principles

1. **Projects first, education last (or omit)** — In crypto, shipped code > degrees
2. **Metrics matter** — "24/24 tests passing", "100+ holders", "deployed on mainnet"
3. **Stack visibility** — Hiring managers scan for technology keywords
4. **Vision statement** — Shows you think beyond the current build
5. **Honest status** — "E2E pending" is better than claiming "production ready"
