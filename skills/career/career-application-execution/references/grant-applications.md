# Grant Applications — Web3/AI Ecosystem Grants

## Overview
Grant applications differ from job applications: you're pitching a project, not yourself. The narrative is "here's what we built and what we'll build with your funding."

## Grant Categories

### 1. Chain Foundation Grants (crypto-native)
- **Solana Foundation** — $200-$400K, milestone-based, ~30 day eval
  - Focus: open-source, public goods, adoption, security
  - Apply: https://solana.org/grants-funding
  - Anyone can apply (individuals, teams, companies)
- **Arbitrum Foundation** — Varies (Foundation + DAO)
  - Focus: adoption, tech structure, sustainable communities
  - Apply: https://arbitrum.foundation/grants
  - Also: UAGP (Uniswap-Arbitrum) $50K-$250K
- **Ethereum Foundation** — Quarterly, $10K-$250K
  - Focus: public goods, research, tooling
  - Caution: frame as AI/utility, not "crypto"

### 2. Protocol/Ecosystem Grants
- **Chainlink BUILD** — Oracle access + co-marketing (not cash)
  - Focus: projects needing oracle/data feeds
  - Apply: https://chain.link/build-program
  - Free Chainlink Functions + CCIP access
- **Alchemy $20M Solana Fund** — Up to $25K infra credits
  - Focus: Solana infrastructure
  - Apply: https://www.alchemy.com/solana-20m-fund
  - 5 biz day response, no lock-in
- **Nosana Grants** — $5K-$50K (USDC/NOS/GPU)
  - Focus: AI infra, agents, dev tools
  - Apply: https://nosana.com/grants/
  - Year-round, ~2 week review

### 3. Accelerator Grants
- **Alliance AI** — $500K (SAFE)
  - Focus: Crypto & AI accelerator
  - Apply: https://alliance.xyz/apply
  - Rolling admissions, interview within 3 days

## Strategy
1. **Lead with proof of work** — existing repos, tests passing, live deployments
2. **Frame for the ecosystem** — "Solana-native" for Solana Foundation, "Arbitrum-ready" for Arbitrum
3. **Reuse narrative** — same core story, tailored per grant
4. **Non-dilutive preferred** — grants don't take equity
5. **Cross-reference hackathon wins** — credibility signal

## Pitfalls
- **ETH ecosystem grants** — ETH price ≠ ecosystem value. Base/Arbitrum are separate ecosystems with their own grants. Frame as "L2 builder" not "ETH developer."
- **"Crypto" framing** — Some non-crypto grants reject crypto projects. Frame as AI/utility, mention blockchain only if relevant.
- **Rolling deadlines** — Most foundation grants are rolling. No rush, but no excuse to delay.
