# Grant Application Patterns — Chain Foundation Grants

## Solana Foundation Grants

**URL:** https://solana.org/grants-funding
**Amount:** $200–$400K (milestone-based)
**Evaluation:** ~30 days
**Focus:** Open-source, public goods, decentralization, adoption, security
**Who can apply:** Individuals, teams, nonprofits, companies, universities

### What They Fund
- Open-source developer tools
- Infrastructure and tooling
- Education and documentation
- Ecosystem adoption projects

### Application Tips
- Lead with Agent Registry as reusable infrastructure
- Emphasize Solana-native (speed, cost, ecosystem)
- Attach hackathon wins as proof of shipping
- Milestone-based: smaller first tranche, scale on delivery

---

## Chainlink BUILD Program

**URL:** https://chain.link/build-program
**Amount:** Oracle access + co-marketing (not cash)
**Focus:** Projects needing oracle infrastructure, data feeds, CCIP
**Benefits:** Free Chainlink Functions, CCIP access, technical mentorship, co-marketing

### What They Fund
- Oracle infrastructure projects
- Cross-chain applications
- Data feed integrations
- Real-world asset tokenization

### Application Tips
- Frame as "Chainlink-powered" — lead with oracle use case
- Agent Shield is a perfect fit: oracle feeds for real-time threat detection
- Emphasize cross-chain (CCIP) for multi-chain agent coordination
- Co-marketing value > cash value for early-stage projects

---

## Arbitrum Foundation Grants

**URL:** https://arbitrum.foundation/grants
**Amount:** Varies (Foundation + DAO + UAGP)
**Focus:** Adoption of Arbitrum chains, technical structure, sustainable communities

### Grant Paths
1. **Foundation Grants** — New program (monitor announcements)
2. **DAO Grant Hub** — Community proposals accepted now
3. **UAGP (Uniswap-Arbitrum)** — $50K–$250K for ecosystem projects

### Application Tips
- AgentForge already 10/10 tests — ready for deployment
- Emphasize L2 leadership (highest revenue among L2s)
- Frame as "AI agent economy infrastructure on Arbitrum"
- If building on Uniswap, apply to UAGP for larger funding

## Common Patterns Across All Grants

| Pattern | Why It Works |
|---------|-------------|
| **Lead with artifact** | "128 tests passing" beats "I plan to build" |
| **Frame as ecosystem value** | "Brings X to [chain]" not "I need money" |
| **Attach hackathon wins** | Proves shipping velocity |
| **Non-dilutive** | Grants don't take equity |
| **Rolling applications** | Apply anytime, no deadline pressure |
| **Milestone-based** | Smaller first tranche, scale on delivery |
| **Reuse narrative** | One core story, customize per chain |
