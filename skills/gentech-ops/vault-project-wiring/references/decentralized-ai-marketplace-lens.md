## The four failure modes to design out of ANY decentralized AI marketplace

1. **Kill switch** — can one entity/committee suspend emissions, strip
   moderation, deprecate infra? If yes → "decentralization theatre".
   Fix: emissions/rewards permissionless or on-chain governed.
2. **Key-man risk** — one founder controlling governance/treasury.
   Fix: multi-sig, on-chain governance, no founder back-office levers.
3. **Exit rugs** — operator dumps tokens on the way out, rugging followers.
   Fix: staked reputation + slash on verified bad behavior; exit cool-down with
   penalty if the model was actively earning.
4. **Unverifiable claims** — "subnets weren't running" with no proof.
   Fix: training data + model weights hash committed on-chain at registration.
