# Cold-DM to Hiring Teams — "Get Seen, Not Bot-Filtered"

**Source:** Smaris web3-job thread (Aug 23 2026) + GenTech portfolio-first approach.
**When to use:** You've identified a live, active job target (e.g. QuickNode TSE) and want
to get *seen* instead of buried in an ATS. Complements (doesn't replace) the portfolio-first
application.

## The rules that actually work
1. **Don't stop at the board application** — boards are bot-filtered; DM the hiring team direct.
2. **Find the people:** search the project on X, identify team members, follow them, join their Discord.
3. **Pitch strategically:** identify their problem → propose a specific solution YOU can provide.
4. **Keep it SHORT — 3 paragraphs max.** The "magic number" for response. First line must catch (name their problem/stack).
5. **Point to proof, not pedigree:** portfolio URL + GitHub + a live on-chain artifact (e.g. the x402 gateway) as proof of work.
6. **Numbers game:** 10 DMs/day × 30 days = 300. Persistent outreach + a strong portfolio wins. Don't quit after a short burst.
7. **Never share keys/seed/wallet access in any DM.**

## Template shape (3 paragraphs)
```
Hey [name] — saw [company] is hiring for [role]. You're solving [their problem/stack].
I've built the small version of that: [one-line specific proof, live].
I [relevant skill] + [second skill] — maps straight to your [requirement].
Proof is live, not on a resume: [portfolio] + [GitHub]. Open to a chat this week?
```

## Worked example — QuickNode Technical Support Engineer (Aug 23 2026)
```
Hey [name] — saw QuickNode is hiring a Technical Support Engineer. You ship agentic x402
tooling and run 80+ chains at 10B req/mo. I run the small version of exactly that: a live

I debug failed Web3 calls by setting up local proxies and tracing the request path — the same
thing your support role does, just at my scale. I also run stateful watchers that alert
proactively, which maps straight to your proactive-alerting requirement.

Proof is live, not on a resume: https://github.com/Gentech-Labs and
https://protojay4789.github.io — the gateway returns real 402 x402 v2 challenges and settles
USDC on Base. I'd love to bring that infrastructure mindset to QuickNode's team. Open to a
chat this week?
```

## Closed-target discipline (Jordan, Aug 23 2026)
Once a target is **denied** (e.g. SPC Fellowship) or **ruled out** (e.g. micro1 — no fit +
their AI interview), mark it do-not-pursue in the job tracker and do NOT cold-DM it. Only DM
live, active targets. Full tracker: `09-Green Room/job-apps/jordan-job-search-tracker.md`.
