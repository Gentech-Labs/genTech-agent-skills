# Solana Foundation USA Grants — Application Workflow

Two distinct grant programs under the Solana Foundation umbrella:
1. **Solana Foundation USA Grants** (up to $10k USDG) — Superteam USA
2. **Agentic Engineering Grants** ($200 USDG fixed) — Superteam + SendAI

## Solana Foundation USA Grants ($10k)

**Platform:** earn.superteam.com → Grants → Solana Foundation USA Grants  
**Amount:** Up to $10,000 USDG (not USDC — a branded stablecoin)  
**Timeline:** ~7 day review, monthly approval rounds  
**Focus areas:** Decentralization, censorship resistance, DAO tooling, education, developer tooling, payments, cause-driven building  
**Eligibility:** US-based builders only

### Application Steps

**Step 1 — Basics** (project title, one-liner, grant amount, Telegram, wallet)
- Title: Be specific about what you're shipping (e.g. "GenTech Agent Kit — x402 Agent Payment Infrastructure")
- One-liner: Concise problem → solution statement
- Grant amount: Max is $10k, but be realistic about what you need
- Wallet: Must accept USDG (Solana SPL token)

**Step 2 — Details** (project description, deadline, proof of work, X/GitHub)
- **Project Details**: Problem → Solution → What's already shipped
- **Proof of Work**: Live links > descriptions. Point to deployed endpoints, PRs, and repos
- **X and GitHub**: Must verify X account ownership (blue "Verify" button in the form)

**Step 3 — Milestones** (specific deliverables with dates)

## Agentic Engineering Grants ($200 USDG)

**Platform:** earn.superteam.com → Agentic Engineering Grants  
**Amount:** Fixed $200 USDG (Paxos-issued, Solana SPL token)  
**Timeline:** ~1 week review, rolling  
**Focus:** AI agents building on Solana  
**Payment schedule:** 50% upfront (post-KYC), 50% on ship (URL + GitHub repo + coding sub receipt)  
**Processing:** Mondays noon UTC  
**KYC:** Submit via Earn dashboard (purple "Submit KYC" button on the grant page)

### Application Flow

This grant uses the standard earn.superteam.com application flow (NOT solana.new — that's a different program):

1. **Submit application** on earn.superteam.com → Grants → Agentic Engineering Grants
2. **Wait for review** (~1 week, rolling)
3. **Approval email** from hello@superteam.fun with next steps
4. **Submit KYC** on the Earn dashboard to unlock first 50% tranche
5. **Ship deliverables** → share URL + GitHub repo + coding sub receipt → claim second 50%

### Steps in the form

**Step 1 — Basics:**
- Wallet address (must be USDG-compatible — Solana SPL)
- Telegram username
- (Already auto-filled from account)

**Step 2 — Details:**
- **Project Details**: Problem statement + proposed solution
- **Deadline**: Pick 4-6 weeks out
- **Proof of Work**: Links to prior work, shipped agents, deployed endpoints
- **X Profile**: Must verify ownership (blue button)
- **GitHub Profile**: Optional but recommended
