# x402 Ecosystem Snapshot — July 2026

Condensed reference for weekly scans. Updated Jul 5, 2026.

## 🔴 Major Change: Protocol Governance Move

The x402 protocol has moved from Coinbase to the **x402 Foundation**:
- **Old:** `github.com/coinbase/x402` — now a development fork
- **New:** `github.com/x402-foundation/x402` — canonical repo (6,252 ★)
- **Homepage:** https://x402.org
- **Impact:** Reduces Coinbase dependency risk. Foundation-governed protocol is more stable for long-term infrastructure bets.
