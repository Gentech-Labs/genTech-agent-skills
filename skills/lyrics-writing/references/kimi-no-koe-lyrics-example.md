## Key Takeaways

1. **HIKARI's default mode** is `[Melodic]` — clean, emotional, JP/EN light sprinkle
2. **HIKARI's alt mode** is `[Scream][Emotional][Melodic]` — soft screaming, controlled intensity, heavier JP/EN
3. Arrow progression consistently builds: `[Soft → Build]` → `[Intense][Crescendo]` → emotional peak → `[Soft][Fading]`
4. Only one scream section in melodic mode (bridge climax); multiple scream-intensity sections in soft-scream mode
5. JP/EN ratio: melodic ~15% JP, soft scream ~30-40% JP
6. Character count (lyric body, no tags/title): ~2,200 chars
7. Clean tags: `[Scream]` replaces `[ScreamSing]` — `[ScreamSing]` DOES NOT WORK in Donna AI
