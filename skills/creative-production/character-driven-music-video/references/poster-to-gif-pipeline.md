# Poster → Animated GIF Pipeline (Seedance 2.0-fast + ffmpeg)

Observed from Vanito's Jul 14 session: final album art poster → animated GIF for hub.

## Pipeline

### Step 1: Animate with Seedance 2.0-fast

Use `mcp__blockrun__blockrun_video` with image-to-video mode:

```
blockrun_video(
  image_url="<final-poster-URL>",
  model="bytedance/seedance-2.0-fast",
  prompt="Subtle cinematic movement. The beam of light gently flickers. The characters have subtle breathing motion. The shadowy crowd sways slowly. Slow, atmospheric motion."
)
```

**Observed cost:** $1.28 for a 5-second clip (img2v, 720p + audio).

**Parameters from this session:**
- Duration: 5 seconds (default)
- Model: bytedance/seedance-2.0-fast
- Source: final album art poster (guitar removed, user-approved)
- Prompt emphasis: subtle, slow, atmospheric — NOT dramatic motion
- Audio auto-generated by Seedance (synced, on by default for text-to-video, off for img2v — set generate_audio=true if needed)

### Step 2: Convert MP4 → GIF with ffmpeg

```
ffmpeg -y -i input.mp4 -vf "fps=10,scale=480:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" output.gif
```

**Parameters from this session:**
- FPS: 10 (smooth enough for subtle motion, keeps file size manageable)
- Scale: 480px wide (good for Telegram inline display)
- Palette gen: max_colors=256 (default — balanced quality/size)
- Output size: ~7.6MB for a 5-second clip at 10fps (50 frames)

### Step 3: Upload to Hub

```
git add music/vanito/<name>.gif
git commit -m "🎬 Animated album art GIF - <song name>"
git push origin main
```

The raw GitHub URL for the GIF: `https://raw.githubusercontent.com/Gentech-Labs/gentechlabs.github.io/main/music/vanito/<name>.gif`

### When to Use This

- User has a final poster/album art they're happy with
- User says "can you gif that photo and give it movement"
- The image has enough depth/atmosphere to look good with subtle motion (light beams, characters breathing, crowd swaying)
- Budget remaining >= $1.50
- Vanito explicitly says YES to the generation. Rule 0 in the main skill still applies: "No more videos unless I say so" — but asking to make a GIF from a poster counts as him saying so

### Limitations

- 5-10 second max for effective looping GIFs
- Subtle motion only — dramatic camera moves or character actions require a full video (see `character-driven-music-video` main skill)
- Artwork text will get smeared in GIF — ensure title text is large enough to survive palette compression
- 7.6MB GIF is Telegram-safe but may not send on mobile data — optimize with `fps=8` for smaller files
